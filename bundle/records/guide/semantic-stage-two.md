# Next stage: semantic map and reviewed journeys

The first semantic pilot adds explicit relationships to individual concept files. All are unreviewed proposals supported by exact captured DWP passages. No rule is executable and no staff approval is implied.

[Read the semantic map and evidence register](https://github.com/chris-page-gov/okf-dwp/blob/main/bundle/semantic-map.md). [Inspect the status, gaps and delivery plan](https://github.com/chris-page-gov/okf-dwp/blob/main/docs/next-stage/README.md).

Start with the capital-disregard candidate and its evidence, duration and assessment-sequence links. Compare the projected user questions with the missing evidence and review requirements. CPAG contents widen topic discovery only; the handbook text and its legal analysis are not present.

Full DMG is a separate acquisition target: 331 PDFs in the metadata census, of which 36 are currently acquired. ADM has a separate 182-PDF census. The seminar website and personal-AI/audio connection remain feasibility work until actual tool calls and room rehearsal pass.
