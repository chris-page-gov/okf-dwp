# Assisted support practitioner

This is a projected extension of the owner's customer-journey request, not an observed staff or claimant persona.

Goal: support source discovery where a person needs help reading, navigating or using digital services. The person should be able to distinguish an unofficial explanation from the original and recognise when extraction is incomplete.

Keyboard and assistive-technology task completion require direct evaluation. An automated retrieval success is not evidence that this person's needs have been met.
