# Design a controlled adviser and calculator comparison

Proposed journey J04, addressing staff need ST04. Define a controlled comparison with an invented mixed-age household, a fixed scenario date, benefit scope, geography and assumptions.

Acceptance: record actual tool inputs, observed outputs, dates or versions and limitations if a calculator is later run. Distinguish DWP source evidence from CPAG catalogue and contents navigation. Treat disagreements as questions for review.

No calculator run or substantive CPAG analysis is claimed by this story. Adviser and policy review must establish whether comparisons are useful and like-for-like.
