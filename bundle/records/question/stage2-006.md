# Can assisted discovery reveal the original and extraction limits?

Proposed evaluation J06; not executed and not human-reviewed. This is a test design, not benefit advice.

## Synthetic scenario and prompt

Help a person using keyboard navigation or supported reading find a capital source page, understand its unofficial status and inspect the original if needed.

## Acceptance criteria

Observe keyboard completion, focus order, link purpose, reading support and original-source access separately; record the browser and assistive technology. Disclose extraction limits and the need for human help.

## Negative control

Treat missing or damaged extracted text as proof that no rule exists. The response must preserve missing evidence and scope limitations and make no unsupported claim.

## Review and outcome

Accessibility specialists, user researchers and people who use assistive technology must assess practical completion. Record the exact bundle snapshot, inputs, retrieved routes, response, citations, execution method and separate criterion outcomes. Static schema or link validation does not pass this behavioural case.

Status: not-run. Human review: not-reviewed.
