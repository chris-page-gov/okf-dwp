# Proposed bounded implementation brief

This file is a work proposal for an owner-invoked local task. It does not authorise publishing, changing client permissions, contacting paid model APIs, or replacing existing production evidence.

## Objective
Create an additive, reproducible evaluation of the UC/DLA date question and make the same source-bound evidence usable through the existing remote MCP, appropriate page tools and a portable file rendering. Reuse the current A-H evaluator and source/engine replay contracts rather than replacing them.

## First preserve and inspect
Use the supplied live observation and exact replay request to reproduce the baseline. Capture raw responses, all diagnostics and full package reconstruction in a new receipt, verifying source and engine identities and SHA-256. Preserve failures. The supplied summary is not a raw trace and must not be relabelled as one.

Inspect relevant code before diagnosing why the original question selects F1123 but no ADM A4 entry. Investigate fixed lexical query limits, ranking, benefit/regime scoping, candidate/resource budgets, dependency semantics, unit boundaries and profile coverage. Keep raw question text separate from any proposed structured case-fact representation. Do not assert the root cause merely from an omission code.

## Evaluate before optimising
Admit an independently reviewed point-in-time reference package and assessor requirements. Keep these assessor files out of all blinded retrieval prompts and indexes. Retain a flat-source baseline and test withheld questions. A generic query-normalisation or dependency change must be separately versioned and tested; a hand-authored DLA fixture can be a development case but not evidence of generalisation.

## Access and delivery
Test remote MCP handshake, manifest, exact source read, diagnostics continuation, stale-context rejection and byte-verified replay per client. Preserve assembly budget separately from transfer budget. Use case IDs and source record identities in durable references; do not promote session-local page refs/cursors to global IDs.

Export a canonical evidence rendering containing the question, assumptions, source and engine identity, exact passages and locators, qualification boundaries, missing facts, unresolved evidence and review status. Generate Markdown/text/HTML from that canonical package, with a derivative-to-canonical mapping. Add Word only as a separately tested M365 projection. Do not mark derivatives complete when they drop qualifications.

For Workbench inspection, use existing saved-case tools and state/revision guards. Do not claim arbitrary new-question search from a saved-case catalogue. Any new cross-tab bridge, widget, MCP App UI or dedicated sidebar extension is a separate proposal with explicit origin, permission and privacy boundaries.

## Deliverables and acceptance
Return an immutable baseline receipt, proposed reviewed-case contract, A-H results, separate answer assessments, client-specific conformance results and a report clearly dividing not-run, attempted, failed and passed conditions. Include exact reproduction commands supported by the inspected repository. Do not invent file paths, engine APIs, successful runs or paid provider access.

No public deployment, source rewriting, default promotion, account configuration or expansion of privileges is part of this brief. A passing transport test must not be described as a correct benefits decision.
