# Preregistered Monday evidence trial

This directory contains the protocol and authored prompts for six paired cases. **No frozen context catalogue or model results exists yet.** The source/legal-body integration and shared engine must be finalised and identified by immutable commits before the exporter can freeze evidence.

Both providers receive the same 256 KiB context budget, question, authored prompts and answer schema. Headings, conditions, continuations, dates and ambiguity must survive into the answer. The older dated trials remain unchanged. Because both the new prompt and context differ, this does not isolate the effect of either change.

See [the beginner guide and exact commands](../../../docs/monday-model-trials.md). The exporter and runner default to no model calls. The unknown-term control must contain no evidence and support no substantive claim. All staff profiles retain their explicit evidence-closure and review obligations.
