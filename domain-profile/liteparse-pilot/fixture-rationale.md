# Source-bound LiteParse pilot fixtures

These cases were selected from frozen GOV.UK PDFs and existing page JSON before any LiteParse outcome was inspected. GPT-6 Sol at medium reasoning authored the selection. The two cross-page controls come from `domain-profile/passage-boundary-review/held-out-controls.json`; the garbled historical amendment is known case-014. They are regression controls. The other windows are baseline-exposed because the repository already has Poppler extraction, but are new to this LiteParse run. None is an independent human review or a blinded prevalence sample.

Stage 1 has 12 varied windows: substantive DMG and ADM passages, two genuine cross-page continuations, the case-014 extraction defect, amendment navigation and a Chapter 84 numerical table. Stage 2 fixes 24 further windows from distinct pages across substantive DMG and ADM chapters. No selected PDF page appears in both stages. Selection was purposeful and non-random to test boundary and layout behaviour; the case counts cannot estimate corpus-wide error rates. A contiguous page window establishes source order. It does not by itself prove a logical paragraph join.

Every case binds a relative PDF path and SHA-256, page JSON path and SHA-256, original one-based PDF page numbers, and each selected page text hash. The critical anchors are literal source phrases. Whitespace is collapsed for ordinary comparisons; case-014 alone removes whitespace for its PDF-verified clean phrase because Poppler inserted spaces within words. This exception tests character retention and does not treat spelling repair as accepted source interpretation. The frozen Poppler text remains a diagnostic.

The amendment sheet visibly has **Remove** and **Insert** columns with paired rows. Chapter 84 Appendix 1 visibly has **From**, **To** and deemed weekly income columns with increasing capital bands. Codex root visually checked PDF pages 2 and 130 respectively, plus case-014 PDF page 28, before the parser run. These model-assisted layout checks support the proposed expectations but are not independent human or specialist review. A parser table passes only when the declared values remain associated with the correct row and column; finding the words anywhere on the page is insufficient.

The stage gate in `protocol.json` stops after the first 12 if critical source material is lost, bounds fail, reviewed controls regress, or no source-checked structural gain is established. The 24-case stage is conditional. The known 28 outliers, nine substantive chapter negative controls and 40 same-budget replay cases are conditional on the further source gate and a separately tested unit-assembly adapter. The replay retains limits of 512 KiB input, 64 nodes, 128 edges and depth 6. No LLM answer or defect-detector calls are part of this pilot. Source retention, table structure, logical-unit assembly, legal applicability and answer quality remain separate claims.
