# DWP learning paths: detailed lesson plan

Design only. Lesson routes are proposed; evidence routes are verified against the local combined corpus. Durations are planning estimates, not observed timings. Each outcome is assessed using the rubric in DESIGN.md.

## P01 — Read evidence before trusting an answer

**Objective:** Build a reproducible claim-to-evidence ledger and stop when the supplied material is insufficient.

**Personas:** welfare-rights-adviser, pensions-specialist, policy-law-reviewer, evidence-assurance-reviewer, knowledge-engineer, assisted-support. **Prerequisites:** None. **Estimated time:** 27 minutes. **Steps:** 8.

**Assessment:** Classify an unseen evidence package, verify one claim and reject one unsupported claim. All mandatory boundaries must pass.

### 1. Baseline and role (3 minutes)

- Outcome: State what success looks like for your role.
- Practice and submitted evidence: Answer three baseline prompts without help; retain them for later comparison.
- Case references: Cross-cutting demonstration activity.
- Existing source anchors: `persona/evidence-assurance-reviewer`.
- Proposed lesson record: `learning/p01/s01`.

### 2. Distinguish the layers (3 minutes)

- Outcome: Separate original guidance, extracted text and project-authored interpretation.
- Practice and submitted evidence: Classify three items and explain the authority each does and does not have.
- Case references: Cross-cutting demonstration activity.
- Existing source anchors: `chapter/77`, `term/dmg-evidence-assessment`.
- Proposed lesson record: `learning/p01/s02`.

### 3. Read the source in context (3 minutes)

- Outcome: Check a paragraph with its heading and continuation.
- Practice and submitted evidence: Capture the locator and a qualification that would be lost in an isolated quotation.
- Case references: Cross-cutting demonstration activity.
- Existing source anchors: `page/77/0020`, `page/77/0021`.
- Proposed lesson record: `learning/p01/s03`.

### 4. Use concepts without overclaiming (3 minutes)

- Outcome: Distinguish a mention tag, semantic assertion and legal applicability.
- Practice and submitted evidence: Explain why each visible link is or is not enough to support a claim.
- Case references: Cross-cutting demonstration activity.
- Existing source anchors: `staff-domain/partner`.
- Proposed lesson record: `learning/p01/s04`.

### 5. Separate search, context and answer (3 minutes)

- Outcome: Identify which operation finds records, assembles evidence or generates an answer.
- Practice and submitted evidence: Draw the three stages and name the artefact returned by each.
- Case references: Cross-cutting demonstration activity.
- Existing source anchors: `persona/knowledge-engineer`.
- Proposed lesson record: `learning/p01/s05`.

### 6. Read insufficiency honestly (3 minutes)

- Outcome: Distinguish retained candidates, required evidence and unresolved obligations.
- Practice and submitted evidence: Write three separately defined denominators and identify an omitted requirement.
- Case references: Cross-cutting demonstration activity.
- Existing source anchors: `staff-domain/calculation`.
- Proposed lesson record: `learning/p01/s06`.

### 7. Make the result accessible (3 minutes)

- Outcome: Explain a result without relying on colour, jargon or pointer-only actions.
- Practice and submitted evidence: Use keyboard navigation and give a plain-English explanation with one source and one gap.
- Case references: Cross-cutting demonstration activity.
- Existing source anchors: `persona/assisted-support`.
- Proposed lesson record: `learning/p01/s07`.

### 8. Foundation assessment (6 minutes)

- Outcome: Apply the evidence rubric independently.
- Practice and submitted evidence: Submit a claim ledger, a refused unsupported conclusion and a reproducible source identity.
- Case references: Cross-cutting demonstration activity.
- Existing source anchors: `term/dmg-evidence-assessment`.
- Proposed lesson record: `learning/p01/s08`.
